# 数据来源与核查状态

钓点更新日期：2026-11-17（Asia/Shanghai）；其余历史核查见各节。

## 天气

- [Open-Meteo 官方 Forecast API](https://open-meteo.com/en/docs)：已读取文档。请求温度、湿度、降水、10m 风速、风向、海平面气压、WMO 天气码；时区 `Asia/Shanghai`，风速明确 `kmh`，7 天逐小时。
- [使用条款](https://open-meteo.com/en/terms)：非商业免费 API 的适用范围与调用限制应在发布前复核。比赛若包含推广、商业化或广告，需要另行确认使用资格。
- [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)：界面显示 Open-Meteo 署名及许可链接。API 的可用性、数据完整性与部署地网络需要分别验证。
- 重庆城市参考中心采用近似 WGS84 `(29.56, 106.55)`，是开发配置的城市级天气请求中心，**不是已测绘钓点、不是用户所在位置、也不作为真实场所坐标来源**。
- 缓存位置与更新时间可追踪；缓存不跨设备、不写 LocalStorage。无天气不输出正常评分。

## 钓点

`src/data/chongqing-spots.json` 已收录 342 条场所资料，本轮净新增 235 条，均有公开来源与查询时间；政府和媒体报道有发布时间，地图记录未提供发布日期。341 条有高德场所/园区/水域参考坐标，保留原始 GCJ-02 坐标、POI ID 与查询时间，经 gcoord 转为 WGS84。万顺镇东风村垂钓基地仅列出，不用村委会坐标代替钓场。264 条配有同一 POI 的高德场所图片。

现行 37 个区县中有 36 个收录场所，渝中区暂为 0；传统主城九区以外的 29 个区县均有条目。全域扩展完成 85 次按区县限制的高德检索，并进行类型筛选、名称及 POI 去重和近邻复核。这是筛选后的资料选集，不是全部钓场目录。现行区划、逐区计数、官方线索及限制见 [重庆全域覆盖](CITYWIDE_COVERAGE.md)；历史材料见 [首批核查记录](REAL_SPOTS_RESEARCH.md) 和 [九区首轮记录](MAIN_CITY_COVERAGE.md)。

所有记录均为 UNKNOWN，未填写 `verifiedAt`，不能进入正式推荐。资料查询时间不是许可核实时间，赛事许可不外推为长期散客开放；旧报道里的鱼种、价格不作为当前数据。坐标仅定位对应园区/水域，不代表允许垂钓的岸段或具体入口。

`src/data/demo-fixtures.ts` 仅有两个虚构测试水域 A/B，均无现实坐标、鱼种或出处。模拟未知与禁钓状态，所有推荐均被阻止；仅在用户显式开启示例模式后展示。

M2 采集清单：场所名称 / 地址 / 坐标及坐标系 / 经营或政府公示链接 / 许可适用日期与条件 / 来源读取日期 / 核实日期 / 复核期限。优先核查明确接受休闲垂钓的经营场所。
