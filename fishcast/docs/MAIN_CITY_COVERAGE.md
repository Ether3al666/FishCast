## 数据证据与区划

- 使用现有高德 JS SDK 的 PlaceSearch（extensions=all）、场所详情及逆地理查询做一次性资料整理。运行时仍只读取静态目录，不自动执行 POI 搜索。未新增密钥或付费服务配置。
- 每个新增场所保留 POI ID、来源链接、原始 GCJ-02、转换后 WGS84 和检索时间。`district` 为高德返回的现行区名，`traditionalDistrict` 专供传统九区检索；`districtEvidence` 保留街镇与归类说明。
- [重庆市政府 2025 年区划调整公告](https://wap.cq.gov.cn/zwgk/zfxxgkml/szfwj/qtgw/202511/t20251107_15148513.html)：原江北、渝北与北碚部分街镇调整到两江新区，渝北五镇调整到北碚。采用街镇对应关系保留传统检索习惯，不将传统分组冒充现行行政区。
- 初次发现旧江北/渝北代码已失效，部分检索会返回全国结果。已舍弃该批结果，改用现行两江新区代码 500157、重庆市限制和逆地理街镇核对。不能确认传统归属的记录不进入九区筛选。
- 排除停车场、商店、协会接待处等类型。T2 / 重庆狂飙 / 起点等同地址别名没有全部重复新增。收录数量为场所资料条目数，仍可能存在尚未识别的同园区记录，不能解释为全部独立经营单位。
- 所有场所仍为 UNKNOWN；地图名称、场所类型和区名不构成营业或垂钓许可证明。鱼种、钓法、收费未核实，不编造评分。

## 产品行为

- 地图页提供九区计数、主城九区和全部场所筛选，可与文字搜索、许可状态筛选组合；地图标记随列表同步变化。
- 对话支持“明天上午，主城九区”“改为江北区”“改为30公里”。区域模式按已收录归属筛选，不受公里半径截断，仍显示相对当前参考位置的直线距离。重新指定公里范围会退出区域模式；同时指定区域和公里会提示澄清。
- 精确设置支持相同范围切换；区域模式隐藏半径滑块。
- 选点天气、天气时段比较、许可核查和 DEMO 隔离保持原有要求。

## 验证

新增地区归属证据、别名去重、范围切换、半径外同区域候选、周边与未知归属排除、单区空结果的单元测试；浏览器覆盖九个入口、现行区名、地图标记同步、移动宽度和精确设置。

本轮通过 lint、typecheck、54 项单元测试、22 项浏览器测试和生产构建。实际高德 SDK 验证九区 100 个标记、江北 5 个标记，真实页面规划统计为 107 总数 / 100 区域内 / 7 区域外；390px 视口无横向溢出、无页面脚本异常。构建保留单包超过 500 kB 的体积提示，无构建错误。
