# 全站首页风格统一

日期：2026-11-17

## 调整范围

- 以现有首页的深炭色、青绿色、衬线标题、水岸摄影和宽松留白为基准。
- 地图、出钓规划、数据说明和未找到路由共用摄影封面；复用已有本地素材，来源仍见 IMAGE_CREDITS.md。
- 地图区县筛选改为开放式布局，候选列表加入对应场所图片；没有实景的条目继续明确标注示意图。
- 规划页统一欢迎区、对话、输入框、草稿、天气指标和场所结果的排版，保留原对话意图识别及真实天气链路。
- 按后续反馈将用户问题改为右侧独立青绿圆角气泡；助手回答在左侧展开，历史消息使用同样的角色样式，手机气泡最多占 90% 宽度。
- 真实地点详情以原 SpotGallery 开篇，接大标题与两栏场所信息；图片来源、失败降级和资料折叠交互保留。
- 数据说明提取为 AboutPage，保留来源、许可、隐私与示例模式功能，统计使用当前 realSpots 数据。
- 统一内容宽度与页脚；修复 1280px 封面偏左、滚动条引起的横向溢出以及手机底部导航遮挡页脚问题。
